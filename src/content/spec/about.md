# 关于界维互动

你好！我是 **Jieice (界维互动)**，一个热爱探索前沿技术的独立开发者与创作者。

## 我在做什么

专注于 AI 智能体编排、虚拟陪伴交互开发与 Godot 引擎底层架构。在这里，我不仅是在"做游戏"，更多的是在探索人机交互的未来边界。我相信未来的软件不仅仅是冰冷的工具，而是具有记忆、视觉甚至情感的虚拟伙伴。

我的日常工作涵盖了从深入研究开源大语言模型 (LLM)，到为 Godot 引擎编写高性能 C++ 拓展插件；从利用 Python 构建复杂的多 Agent 协作系统，到使用前端框架打磨极速响应的用户界面。

## 核心技术栈

**AI 智能体开发** — LLM 提示工程、RAG 架构、语音克隆 (TTS)、视觉识别 (VLM)、Agentic 框架编排

**游戏引擎底层** — Godot 4.x 开发、C++ GDExtension、物理交互模拟、性能优化与渲染管线

**虚拟角色 (Live2D)** — 原生 Cubism SDK (C++/JS)、LipSync 算法融合、角色物理动态配置与互动开发
