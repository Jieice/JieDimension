2 款已上线 · 5+ 原型 · 6+ 年开发

你好，我是 Jieice，界维互动工作室的主理人。我是一名独立游戏开发者，专注于 Godot 引擎、TapTap Maker 平台与 Web 游戏原型的开发。

我做过的事情横跨游戏全栈：从 Godot 的 C++ GDExtension、Lua 业务层，到 Web 端的可玩游戏原型；从 TapTap 小游戏的云存档与排行榜系统，到 AI Agent 编排和虚拟角色交互。我喜欢把可运行的原型放到第一屏——可玩比空谈更重要。

目前已上线 TapTap 的作品包括横屏夜钓模拟《班后钓鱼》和竖屏弹幕生存《界维守卫》。闲暇时间会汉化一些增量游戏经典，并在 itch.io 上发布 Game Jam 原型。
