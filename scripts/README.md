# 🛠️ 工具脚本

这里存放项目的工具脚本。

---

## 📜 脚本列表

### 1. deploy.bat
**用途**：快速部署到 GitHub Pages  
**使用**：双击运行或在项目根目录运行 `deploy.bat`

**功能**：
- 自动添加所有修改
- 提交更改
- 推送到 GitHub
- 触发自动构建

**适用场景**：日常更新内容后

---

### 2. force-deploy.bat
**用途**：强制重新部署（清理后部署）  
**使用**：双击运行

**功能**：
- 清理旧的 Git 配置
- 重新初始化仓库
- 强制推送所有内容
- 添加 GitHub Actions 配置

**适用场景**：
- 遇到部署问题需要重置
- Git 历史混乱需要清理
- 首次部署时

---

## 🚀 快速使用

### 日常更新流程

1. **编辑文件**（添加游戏、写博客等）
2. **保存所有更改**
3. **运行部署**：
   - 在根目录双击 `deploy.bat`
   - 或在根目录运行：`.\scripts\deploy.bat`
4. **等待构建**（2-3分钟）
5. **访问网站**查看更新

---

## ⚠️ 注意事项

- 部署前确保所有文件已保存
- 部署脚本会自动提交所有更改
- 如果推送失败，检查网络连接
- 首次使用可能需要输入 GitHub 凭据

---

## 🔧 自定义脚本

如果你想创建自己的脚本：

1. 在本文件夹创建 `.bat` 文件
2. 编写命令
3. 在根目录创建调用脚本（可选）

**示例**：
```batch
@echo off
echo 执行自定义任务...
cd D:\Blog
# 你的命令
pause
```
