## 项目简介

这是为 **Godot 4.x** 引擎深度开发的基于 C++ 底层的 Live2D Cubism 渲染插件。旨在为 Godot 开发者提供高性能、原生的 Live2D 角色导入与控制能力。

### 🌟 核心特性

- **🚀 原生高性能**：使用 C++ (GDExtension) 编写，彻底释放 Godot 渲染管线的潜力。
- **⚙️ 全功能支持**：完整实现 Live2D Cubism Core 的参数控制、口型同步(LipSync)与物理系统。
- **🎮 节点化集成**：在 Godot 编辑器中作为原生 Node 节点使用，无缝衔接现有的 GDScript 逻辑。

---

## 💻 适用场景

非常适合用于开发：
1. 包含精美 Live2D 立绘的视觉小说 (Visual Novels)。
2. 需要高互动性虚拟角色的桌面宠物/伴侣软件。
3. 任何需要表现细腻全动态 2D 角色的 Godot 游戏项目。
