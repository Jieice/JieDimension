## 游戏简介

这是一款基于 HTML5 技术开发的网页游戏，可以在浏览器中直接运行，无需下载安装。

### 游戏特色

- **跨平台**：支持 PC、手机、平板等所有设备
- **即点即玩**：无需下载，打开网页即可游玩
- **轻量级**：优化的资源加载，流畅的游戏体验
- **创新玩法**：独特的游戏机制和关卡设计

### 技术实现

- 使用 **HTML5 Canvas** 或 **WebGL** 渲染
- 响应式设计，适配各种屏幕尺寸
- 可能使用 Godot、Phaser、PixiJS 等框架

### 开发状态

正在积极开发中，敬请期待！

## 🎮 如何上传你的 HTML5 游戏？

如果你想把自己的 HTML5 游戏添加到这个网站：

1. **查看详细指南**：[HTML5游戏上传指南](/JieDimension/docs/HTML5游戏上传指南.html)

2. **简要步骤**：
   - 将游戏文件复制到 `assets/games/your-game/`
   - 确保有 `index.html` 入口文件
   - 创建游戏介绍页面并嵌入游戏
   - 推送到 GitHub

3. **优势**：
   - 访客可以直接在线试玩
   - 无需下载安装
   - 支持全屏模式
   - 跨平台访问

---

## 🔧 从 Godot 导出

如果你用 Godot 开发游戏：

1. 项目 → 导出
2. 选择 "HTML5"
3. 导出所有文件
4. 复制到 `assets/games/` 文件夹
5. 按照指南创建展示页面
