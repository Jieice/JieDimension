## 📝 文件功能详解

### ⚙️ 配置文件

#### `_config.yml` - 主配置文件
```yaml
title: JieDimension Studio        # 网站标题
url: https://jieice.github.io     # 网站URL
baseurl: "/JieDimension"          # 子路径
author:                           # 作者信息
  name: JieDimension
  email: 3348149202@qq.com
```
**何时修改**：更改网站标题、联系方式、域名时

#### `Gemfile` - Ruby依赖
定义了 Jekyll 和插件的版本，一般不需要修改。

---

### 🎮 内容文件

#### 游戏文件 (`_games/*.md`)
每个游戏一个 Markdown 文件，包含：
- Front Matter（YAML 头部）：标题、平台、状态、链接
- 正文：游戏介绍、特色、技术等

**示例结构**：
```markdown
---
title: 游戏名称
platform: 平台
icon: 🎮
status: 开发状态
links:
  - text: 链接文字
    url: "链接地址"
---

游戏介绍内容...
```

#### 博客文章 (`_posts/*.md`)
文件命名规则：`YYYY-MM-DD-title.md`

**示例**：`2025-10-06-horror-game-devlog.md`

```markdown
---
layout: post
title: 文章标题
date: 2025-10-06 10:00:00 +0800
author: JieDimension
tags: [标签1, 标签2]
---

文章内容...
```

---

### 🎨 样式文件

#### `assets/css/main.css`
包含所有网站样式：
- CSS 变量（颜色主题）
- 导航栏样式
- 游戏卡片样式
- 博客样式
- 响应式布局

**主题颜色变量**（在文件开头）：
```css
:root {
  --bg-primary: #1a1d23;      /* 主背景色 */
  --accent-primary: #6c63ff;  /* 主题色 */
  --text-primary: #e4e6eb;    /* 主要文字颜色 */
}
```

## 🔄 工作流程

### 添加新游戏
1. 在 `_games/` 创建 `new-game.md`
2. 填写 Front Matter 和介绍
3. 提交并推送

### 写新博客
1. 在 `_posts/` 创建 `YYYY-MM-DD-title.md`
2. 编写内容
3. 提交并推送

### 修改样式
1. 编辑 `assets/css/main.css`
2. 修改 CSS 变量或具体样式
3. 提交并推送

### 更新配置
1. 编辑 `_config.yml`
2. 修改网站信息
3. 提交并推送

---

## 📦 部署流程

1. **本地修改**：编辑文件
2. **运行部署**：双击 `deploy.bat`
3. **自动构建**：GitHub Actions 自动构建
4. **网站更新**：2-3分钟后生效
