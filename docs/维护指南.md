## ➕ 添加新内容

### 1. 添加新游戏作品

**步骤：**

1. 在 `_games/` 文件夹创建新文件，如 `my-new-game.md`

2. 复制以下模板并修改：

```markdown
---
title: 游戏名称
platform: PC / Android / Web
icon: 🎮
status: 开发中 / 已发布 / 测试中
date: 2025-10-05
links:
  - text: 下载游戏
    url: "https://example.com"
    external: true
  - text: 游戏介绍视频
    url: "https://youtube.com/xxx"
    external: true
---

## 游戏简介

简短描述游戏是什么...

### 游戏特色

- **特色1**：描述
- **特色2**：描述
- **特色3**：描述

### 技术亮点

使用了什么技术...

### 开发状态

目前的开发进度...

---

*一句话标语或引用*
```

3. 保存文件

4. **添加游戏截图**（可选但推荐）：
   - 在 `assets/images/` 创建游戏文件夹（如果不存在就创建）
   - 放入截图：`game-screenshot-1.jpg`
   - 在游戏介绍中引用：
   ```markdown
   ![游戏截图](/JieDimension/assets/images/my-game/screenshot-1.jpg)
   ```

5. 运行 `deploy.bat` 部署

---

### 2. 写新博客文章

**步骤：**

1. 在 `_posts/` 文件夹创建新文件

2. **文件命名规则**：`YYYY-MM-DD-title.md`
   - 例如：`2025-10-06-godot-tutorial.md`

3. 复制以下模板：

```markdown
---
layout: post
title: 文章标题
date: 2025-10-06 14:30:00 +0800
author: JieDimension
tags: [游戏开发, Godot, 技术分享]
---

## 引言

介绍这篇文章要讲什么...

## 正文

### 小标题1

内容...

### 小标题2

内容...

## 总结

总结一下...

---

*欢迎在邮件中与我交流：3348149202@qq.com*
```

4. 编写内容（支持 Markdown 语法）

5. 保存并部署

**Markdown 常用语法**：

```markdown
# 一级标题
## 二级标题
### 三级标题

**粗体文字**
*斜体文字*

- 列表项1
- 列表项2

1. 有序列表1
2. 有序列表2

[链接文字](https://example.com)

![图片描述](/JieDimension/assets/images/picture.jpg)

`行内代码`

​```python
# 代码块
print("Hello World")
​```
```

### 3. 添加游戏截图/图片

**步骤：**

1. 创建图片文件夹（如果不存在）：
   ```
   assets/images/
   ```

2. 按游戏分类存放：
   ```
   assets/images/
   ├── horror-game/
   │   ├── screenshot-1.jpg
   │   └── screenshot-2.jpg
   └── mobile-defender/
       └── gameplay.jpg
   ```

3. 在对应的 Markdown 文件中引用：
   ```markdown
   ![游戏截图](/JieDimension/assets/images/horror-game/screenshot-1.jpg)
   ```

4. **图片优化建议**：
   - 格式：JPG（照片）、PNG（透明背景）
   - 大小：控制在 500KB 以内
   - 尺寸：宽度不超过 1920px

## ✏️ 修改现有内容

### 更新游戏信息

1. 打开对应的游戏文件：`_games/horror-game.md`
2. 修改内容或 Front Matter
3. 保存并部署

**常见修改**：

- 更新状态：`status: 已发布`
- 更新链接：修改 `links` 部分的 URL
- 添加新内容：在正文中添加段落

---

### 更新关于页面

1. 打开 `about.md`
2. 修改个人简介、联系方式等
3. 保存并部署

---

### 修改网站基本信息

1. 打开 `_config.yml`
2. 修改相应字段：

```yaml
title: 新的网站标题
tagline: 新的标语
description: 新的描述
author:
  email: 新的邮箱
```

3. 保存并部署

⚠️ **注意**：修改 `_config.yml` 后，本地开发需要重启服务器。

## 🎨 样式调整

### 修改颜色主题

1. 打开 `assets/css/main.css`

2. 找到顶部的 CSS 变量（大约第 3-25 行）：

```css
:root {
  /* 暗色配色 */
  --bg-primary: #1a1d23;        /* 主背景色 */
  --bg-secondary: #23272f;      /* 次背景色 */
  --text-primary: #e4e6eb;      /* 主要文字颜色 */
  --accent-primary: #6c63ff;    /* 主题色（紫色） */
}
```

3. 修改颜色值（使用16进制颜色代码）

4. 保存并部署

**推荐配色工具**：
- https://coolors.co/ - 配色方案生成器
- https://color.adobe.com/ - Adobe 配色工具

---

### 修改字体大小

在 `main.css` 中找到 `body` 或具体元素的 `font-size`：

```css
body {
  font-size: 16px;  /* 改为 18px 让文字更大 */
}

.hero h1 {
  font-size: 3rem;  /* 改为 3.5rem 让标题更大 */
}
```

---

### 调整卡片样式

找到 `.game-card` 相关样式：

```css
.game-card {
  border-radius: 12px;  /* 圆角大小 */
  /* 其他样式... */
}

.game-card:hover {
  transform: translateY(-8px);  /* 悬停上移距离 */
}
```

## 🚀 部署更新

### 方法一：使用脚本（推荐）

**Windows 用户**：

1. 保存所有修改的文件
2. 双击运行 `deploy.bat`
3. 等待脚本完成
4. 访问网站查看更新（2-3分钟后生效）

### 方法二：手动命令

在项目目录（`D:\Blog`）打开终端：

```bash
# 1. 查看修改
git status

# 2. 添加所有修改
git add .

# 3. 提交（修改描述信息）
git commit -m "更新游戏截图和博客文章"

# 4. 推送到 GitHub
git push origin master
```

### 方法三：使用 GitHub 网页编辑

1. 访问仓库：https://github.com/Jieice/JieDimension
2. 找到要修改的文件
3. 点击编辑（铅笔图标）
4. 修改内容
5. 点击 "Commit changes"

## 🆘 常见问题

### Q1: 网站没有更新怎么办？

**检查步骤**：

1. 确认代码已推送到 GitHub
   - 访问 https://github.com/Jieice/JieDimension
   - 查看最新提交时间

2. 检查 GitHub Actions 构建状态
   - 访问 https://github.com/Jieice/JieDimension/actions
   - 查看是否有构建失败（红色 ❌）

3. 清除浏览器缓存
   - 按 `Ctrl + F5` 强制刷新
   - 或使用无痕模式访问

4. 等待更长时间
   - 有时需要 5-10 分钟

---

### Q2: 图片显示不出来？

**可能原因**：

1. **路径错误**：
   - ❌ 错误：`/assets/images/pic.jpg`
   - ✅ 正确：`/JieDimension/assets/images/pic.jpg`
   - 💡 记得加 `/JieDimension` 前缀

2. **图片未提交**：
   - 确保图片文件已用 `git add` 添加

3. **文件名大小写**：
   - Windows 不区分大小写，但 GitHub 区分
   - 确保引用和文件名完全一致

---

### Q3: 样式错乱怎么办？

**解决方法**：

1. 检查 CSS 语法错误
   - 确保每个 `{` 有对应的 `}`
   - 确保属性后有分号 `;`

2. 清除浏览器缓存并刷新

3. 检查 `_config.yml` 中的 `baseurl` 设置

---

### Q4: 本地预览网站

如果想在推送前本地预览：

```bash
# 安装依赖（首次运行）
bundle install

# 启动本地服务器
bundle exec jekyll serve --config _config.yml,_config_dev.yml

# 浏览器访问
http://localhost:4000/JieDimension
```

---

### Q5: 推送时需要输入用户名密码？

GitHub 现在使用 **Personal Access Token**：

1. 访问：https://github.com/settings/tokens
2. 点击 "Generate new token (classic)"
3. 勾选 `repo` 权限
4. 生成并复制 token
5. 推送时，用户名填 `Jieice`，密码填 token

或配置 SSH：https://docs.github.com/zh/authentication
