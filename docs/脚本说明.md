## 📂 scripts/ 文件夹中的脚本

### scripts/deploy.bat

原始的部署脚本，现在不推荐直接使用。

**功能**：基础的 git 提交推送功能

**区别**：
- 没有中文提示
- 没有进度显示
- 没有成功信息
- 界面较简陋

### scripts/force-deploy.bat

强制重新部署脚本。

**用途**：当遇到严重的 Git 问题时使用

**功能**：
- 清理 Git 配置
- 重新初始化仓库
- 强制推送所有内容

**⚠️ 注意**：会清除本地 Git 历史，慎用！

**使用场景**：
- Git 历史混乱
- 推送冲突无法解决
- 仓库损坏需要重建

## 🎯 日常使用建议

### 推荐工作流程

```
1. 修改文件（添加游戏、写博客、修改样式等）
   ↓
2. 保存所有修改
   ↓
3. 双击运行「部署.bat」
   ↓
4. 等待脚本完成
   ↓
5. 等待 2-3 分钟
   ↓
6. 访问网站查看更新
```

### 何时使用不同脚本

| 场景 | 使用脚本 |
|------|---------|
| **日常更新内容** | 部署.bat ✅ |
| **添加新游戏** | 部署.bat ✅ |
| **写博客** | 部署.bat ✅ |
| **修改样式** | 部署.bat ✅ |
| **Git 出问题** | scripts/force-deploy.bat ⚠️ |
| **想手动操作** | 手动 git 命令 🔧 |

## 🔧 手动部署（高级）

如果你想更精确地控制提交内容：

```bash
# 1. 查看修改
git status

# 2. 添加特定文件
git add _games/new-game.md
git add assets/images/screenshot.jpg

# 3. 提交（自定义提交信息）
git commit -m "添加新游戏：XXX"

# 4. 推送
git push origin master
```

## ❓ 常见问题

### Q1: 脚本运行失败怎么办？

**检查清单**：
1. 网络连接是否正常？
2. 是否需要输入 GitHub 凭据？
3. 是否有推送冲突？

**解决方法**：
- 检查错误信息
- 先运行 `git pull` 拉取最新代码
- 查看 [常见问题文档](常见问题.md)

### Q2: 推送后网站没更新？

**原因**：
1. 构建需要 2-3 分钟
2. 浏览器缓存

**解决**：
1. 等待更长时间（最多 5 分钟）
2. 访问 Actions 查看构建状态
3. 硬刷新浏览器（Ctrl + F5）

### Q3: 想修改提交信息？

**方法**：
- 使用手动部署方式
- 或编辑 `部署.bat`，修改 commit 信息

### Q4: 可以在其他电脑使用这些脚本吗？

**可以！**

前提条件：
1. 已安装 Git
2. 已配置 GitHub 凭据
3. 克隆了项目到本地

## 💡 进阶技巧

### 自定义提交信息

修改 `部署.bat` 中的这一行：
```batch
git commit -m "添加水果合成游戏 - 可在线试玩的HTML5游戏"
                   ↑ 改成你想要的提交信息
```

### 添加部署前检查

在 `部署.bat` 开头添加：
```batch
:: 检查是否有未保存的文件
if exist "*.tmp" (
    echo 警告：发现临时文件！
    pause
)
```

### 自动打开网站

在 `部署.bat` 结尾添加：
```batch
:: 5秒后自动打开网站
timeout /t 5
start https://jieice.github.io/JieDimension/
```
