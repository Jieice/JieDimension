快速解答最常见的问题。

## 🚀 部署相关

### Q1: 推送到 GitHub 会把所有文件都上传吗？

**A:** 是的，但有例外：

- ✅ **会上传**：Markdown、CSS、优化后的图片、配置文件
- ❌ **不会上传**：被 `.gitignore` 排除的文件（游戏安装包、临时文件等）

**查看会上传什么**：
```bash
git status    # 查看将要提交的文件
```

---

### Q2: 文件多了网站会不会变卡？

**A:** 不会！原因：

1. **访客看的是生成的网站**，不是源文件
2. Jekyll 会把 Markdown 转成静态 HTML
3. 只有网站需要的文件（HTML/CSS/图片）会被访问

**会影响的**：
- ⚠️ 仓库大小（推送变慢）
- ⚠️ 克隆速度

**不影响**：
- ✅ 网站访问速度
- ✅ 用户体验

**建议**：参考 [文件管理指南](文件管理指南.md)

---

### Q3: deploy.bat 推送失败怎么办？

**可能原因及解决方法**：

1. **网络问题**
   ```bash
   # 检查网络连接
   ping github.com
   ```

2. **需要登录**
   - 用户名：你的 GitHub 用户名
   - 密码：Personal Access Token（不是登录密码）
   - 创建 Token：https://github.com/settings/tokens

3. **推送冲突**
   ```bash
   git pull origin master  # 先拉取
   git push origin master  # 再推送
   ```

## 📝 内容相关

### Q4: 如何添加游戏截图？

**步骤**：

1. **压缩图片**：使用 TinyPNG.com，目标 < 300KB
2. **存放位置**：`assets/images/游戏名/screenshot.jpg`
3. **在 Markdown 中引用**：
   ```markdown
   ![截图](/JieDimension/assets/images/game/screenshot.jpg)
   ```
4. **推送**：运行 `deploy.bat`

**注意**：路径必须以 `/JieDimension` 开头！

---

### Q5: 图片不显示怎么办？

**常见原因**：

1. **路径错误**
   - ❌ `/assets/images/pic.jpg`
   - ✅ `/JieDimension/assets/images/pic.jpg`

2. **文件名大小写**
   - Windows 不区分，但 GitHub 区分
   - `Image.jpg` ≠ `image.jpg`

3. **图片未推送**
   ```bash
   git status  # 检查图片是否被添加
   ```

---

### Q6: 博客文章不显示？

**检查清单**：

1. **文件命名**：必须是 `YYYY-MM-DD-title.md`
   - ✅ `2025-10-05-welcome.md`
   - ❌ `welcome.md`

2. **Front Matter**：必须有正确的 YAML 头部
   ```yaml
   ---
   layout: post
   title: 标题
   date: 2025-10-05 10:00:00 +0800
   ---
   ```

3. **位置**：必须在 `_posts/` 文件夹

4. **推送**：确保已推送到 GitHub

## 🎨 样式相关

### Q7: 修改 CSS 后没生效？

**解决方法**：

1. **硬刷新浏览器**
   - Windows: `Ctrl + F5`
   - Mac: `Cmd + Shift + R`

2. **清除缓存**
   - Chrome: 开发者工具 → Network → Disable cache

3. **检查是否推送**
   ```bash
   git status
   git log  # 查看最近提交
   ```

4. **等待构建**
   - 访问：https://github.com/Jieice/JieDimension/actions
   - 确保构建成功（绿色 ✓）

---

### Q8: 怎么改网站颜色？

**步骤**：

1. 打开 `assets/css/main.css`
2. 找到 CSS 变量（文件开头）：
   ```css
   :root {
     --accent-primary: #6c63ff;  /* 改这里 */
   }
   ```
3. 改成你想要的颜色（16进制）
4. 保存并推送

**颜色工具**：https://coolors.co/

## 🔧 技术相关

### Q9: 怎么本地预览网站？

**步骤**：

1. **安装 Ruby**（首次）
   - Windows: https://rubyinstaller.org/

2. **安装依赖**（首次）
   ```bash
   cd D:\Blog
   bundle install
   ```

3. **启动服务器**
   ```bash
   bundle exec jekyll serve
   ```

4. **访问**：http://localhost:4000/JieDimension

---

### Q10: 修改 _config.yml 后本地预览没更新？

**A:** 修改配置文件后必须重启 Jekyll 服务器

```bash
# 按 Ctrl+C 停止服务器
# 重新启动
bundle exec jekyll serve
```

## 📦 文件管理

### Q11: 可以把游戏安装包放在项目里吗？

**A:** ❌ **强烈不建议**

**原因**：
- 游戏包通常很大（几十MB到几GB）
- 会严重拖慢仓库
- GitHub 单文件限制 100MB

**替代方案**：
- GitHub Releases（推荐）
- Itch.io / TapTap 等平台
- 云盘（OneDrive / 百度云）

详见：[文件管理指南](文件管理指南.md)

---

### Q12: 仓库太大了怎么办？

**检查大小**：
```bash
git count-objects -vH
```

**清理方法**：

1. **删除大文件**（如果刚添加）
   ```bash
   git rm --cached 大文件.exe
   git commit -m "删除大文件"
   git push
   ```

2. **从历史记录删除**（如果已提交多次）
   - 使用 BFG Repo-Cleaner
   - 参考：[文件管理指南](文件管理指南.md)

## 🆘 构建错误

### Q13: GitHub Actions 构建失败？

**排查步骤**：

1. **查看错误日志**
   - 访问：https://github.com/Jieice/JieDimension/actions
   - 点击失败的构建
   - 查看详细错误信息

2. **常见错误**：
   - YAML 语法错误（Front Matter）
   - Liquid 模板语法错误
   - 插件不兼容

3. **回滚到正常版本**
   ```bash
   git log  # 找到正常的提交
   git revert HEAD  # 撤销最近的提交
   git push
   ```

---

### Q14: 网站显示 404？

**可能原因**：

1. **GitHub Pages 未启用**
   - 检查：https://github.com/Jieice/JieDimension/settings/pages

2. **URL 错误**
   - ✅ `https://jieice.github.io/JieDimension/`
   - ❌ `https://jieice.github.io/`

3. **构建失败**
   - 检查 Actions 构建状态

### Q16: 多台电脑如何同步？

**步骤**：

1. **首台电脑**：推送更改
   ```bash
   git push
   ```

2. **另一台电脑**：拉取更改
   ```bash
   git pull
   ```

3. **注意**：推送前先拉取，避免冲突
