# ✅ 网站维护检查清单

定期使用本清单确保网站运行良好。

---

## 📅 每周检查（15分钟）

### 基础检查
- [ ] 访问网站确认正常显示
  - 首页：https://jieice.github.io/JieDimension/
  - 游戏页面：https://jieice.github.io/JieDimension/games/
  - 博客页面：https://jieice.github.io/JieDimension/blog/
  - 关于页面：https://jieice.github.io/JieDimension/about/

### 技术检查
- [ ] 检查 GitHub Actions 构建状态
  - 访问：https://github.com/Jieice/JieDimension/actions
  - 确保最近的构建是 ✅ 成功状态

### 内容检查
- [ ] 检查是否有需要回复的邮件
- [ ] 浏览器不同设备测试（可选）
  - PC 桌面
  - 手机竖屏
  - 平板横屏

---

## 📅 每月任务（1-2小时）

### 内容更新
- [ ] 发布至少一篇新博客文章
- [ ] 更新游戏开发进度状态
- [ ] 检查并更新失效链接

### 资源优化
- [ ] 添加或更新游戏截图
- [ ] 优化现有图片大小
- [ ] 检查页面加载速度

### 数据备份
- [ ] 备份整个项目到云盘
  - 压缩为 `Blog-Backup-YYYY-MM.zip`
  - 上传到 OneDrive/百度云

### SEO 优化
- [ ] 更新页面描述
- [ ] 检查关键词使用
- [ ] 查看 Google 搜索收录情况（可选）

---

## 📅 每季度任务（半天）

### 大型更新
- [ ] 设计优化或重构
- [ ] 添加新功能特性
- [ ] 更新技术栈版本

### 内容审查
- [ ] 审查所有现有内容
- [ ] 删除或归档过时信息
- [ ] 更新游戏状态和链接

### 性能优化
- [ ] 检查网站性能指标
- [ ] 优化图片和资源
- [ ] 清理无用文件

### 安全检查
- [ ] 更新依赖包版本
- [ ] 检查 GitHub 安全警告
- [ ] 审查访问日志（如有）

---

## 🎮 游戏发布前检查清单

当有新游戏要发布时：

### 准备工作
- [ ] 准备游戏截图（至少3张）
- [ ] 准备游戏图标
- [ ] 准备游戏描述文案
- [ ] 准备下载/试玩链接

### 创建游戏页面
- [ ] 在 `_games/` 创建游戏文件
- [ ] 填写完整的游戏信息
- [ ] 添加游戏截图到 `assets/images/`
- [ ] 测试所有链接有效

### 推广准备
- [ ] 撰写发布公告博客
- [ ] 准备社交媒体文案
- [ ] 更新首页展示

### 发布后
- [ ] 推送更新到 GitHub
- [ ] 确认网站正常更新
- [ ] 分享到社交平台

## 🐛 故障排查检查清单

网站出问题时的排查步骤：

### 第一步：确认问题
- [ ] 问题具体描述是什么？
- [ ] 在什么设备/浏览器上出现？
- [ ] 什么时候开始的？

### 第二步：基础检查
- [ ] GitHub Actions 构建是否成功？
- [ ] 最近推送的代码是否有错？
- [ ] 浏览器缓存清除了吗？

### 第三步：常见问题
- [ ] 图片路径是否正确？（`/JieDimension` 前缀）
- [ ] `_config.yml` 配置是否正确？
- [ ] CSS 语法是否有错误？
- [ ] Markdown Front Matter 格式正确吗？

### 第四步：回滚
如果无法快速修复：
- [ ] 查看 Git 历史记录
- [ ] 回滚到上一个正常版本
- [ ] 重新推送
