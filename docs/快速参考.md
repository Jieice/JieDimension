## 🐛 故障排查

### 网站没更新？
1. 刷新浏览器 `Ctrl + F5`
2. 检查 Actions 构建状态
3. 等待 5-10 分钟

### 图片不显示？
1. 检查路径是否以 `/JieDimension` 开头
2. 确认文件已提交推送
3. 检查文件名大小写

### 推送失败？
1. 检查网络连接
2. 使用 Personal Access Token
3. 检查远程仓库地址
