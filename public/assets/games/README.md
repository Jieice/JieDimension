# 🎮 HTML5 游戏文件夹

这里存放可以在线试玩的 HTML5 游戏。

---

## 📂 文件夹结构

每个游戏应该有自己的文件夹：

```
assets/games/
├── game1/
│   ├── index.html         # 游戏入口（必需）
│   ├── game.js            # 游戏代码
│   ├── style.css          # 样式
│   └── assets/            # 游戏资源
│       ├── images/
│       ├── sounds/
│       └── ...
├── game2/
│   └── ...
└── README.md              # 本文件
```

---

## 📤 如何添加游戏

### 1. 创建游戏文件夹

在本目录创建新文件夹，命名为游戏名（使用英文，小写，用连字符）：

```
good-name       ✓
my-game         ✓
space_shooter   ✓

Bad Name        ✗
我的游戏        ✗
```

### 2. 复制游戏文件

将你的游戏的**所有文件**复制到新文件夹：

- 必须有 `index.html` 作为入口
- 保持原有的目录结构
- 使用相对路径引用资源

### 3. 测试游戏

**本地测试**：
1. 双击 `index.html`
2. 检查是否正常运行
3. 检查所有资源是否加载

**在线测试**（推送后）：
1. 访问：`https://jieice.github.io/JieDimension/assets/games/your-game/`
2. 测试游戏功能

### 4. 创建游戏页面

在 `_games/` 文件夹创建游戏介绍页面，嵌入游戏。

详见：[HTML5游戏上传指南](../../docs/HTML5游戏上传指南.md)

## 📏 大小限制

| 建议 | 大小 |
|------|------|
| **推荐** | < 10MB |
| **可接受** | 10-20MB |
| **需优化** | > 20MB |

**提示**：游戏太大会导致：
- 加载时间长
- 仓库推送慢
- 影响用户体验

---

## ✅ 检查清单

添加游戏前检查：

- [ ] 游戏文件夹名称规范（小写英文）
- [ ] 有 `index.html` 入口文件
- [ ] 所有资源使用相对路径
- [ ] 本地测试通过
- [ ] 游戏大小合理（< 20MB）

## 🎯 示例

### 好的例子

```
assets/games/
└── space-shooter/          ✓ 规范的文件夹名
    ├── index.html         ✓ 入口文件
    ├── game.js
    ├── style.css
    └── assets/
        ├── images/        ✓ 资源分类清晰

        │   └── enemy.png  (40KB)
        └── sounds/
            └── shoot.mp3  (30KB)
    
总大小：约 300KB ✓ 大小合理
```

### 需要改进的例子

```
assets/games/
└── MyAwesomeGame/          ✗ 大写字母
    ├── game.html          ✗ 应该叫 index.html
    ├── main.js
    └── images/
        ├── bg.png         (5MB) ✗ 图片太大
        └── player.png     (2MB) ✗ 需要压缩

总大小：15MB ✗ 需要优化
```

## 🔧 优化技巧

### 图片优化
1. 使用 TinyPNG.com 压缩
2. 降低分辨率（游戏内不需要超高清）
3. 使用雪碧图（Sprite Sheet）

### 音频优化
1. 使用 MP3 格式（OGG 也可以）
2. 降低比特率（128kbps 足够游戏使用）
3. 只保留必要的音效

### 代码优化
1. 压缩 JavaScript 代码
2. 移除 console.log
3. 合并文件
